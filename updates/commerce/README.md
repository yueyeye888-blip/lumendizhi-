带平台余额的 YorkeAI 商城部署在接单前预扣订单的实际售价。超过 3 分钟仍在待领取队列的地址单会被原子撤出，再由现有账务模块将实扣金额退回原账户。网站每 30 秒对账，领取端也会检查新单的截止时间。已经领取的订单按原有流程结算。

此目录保存商城侧补丁及回归测试。恢复 2026-11-16 快照时，完整恢复脚本会应用领取端更新。该快照早于商城钱包，若另行安装钱包版商城，可在 Lumenziyuan 商城源码基线 `aa9fa7ecabe3fccf6a020576204f860605fd54f0` 使用 `git apply --check <补丁路径>` 后执行 `git apply <补丁路径>`，再按商城原部署流程发布。Windows 接单任务使用本仓库的 `app/lib/site-order-queue.mjs`。
